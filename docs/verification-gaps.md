# 验证缺口

本文件记录当前证据不足的判断与回归覆盖缺口，核对日期：2026-10-06。
下列项目按各自证据记录状态，不因包结构或工程质量门通过而关闭行为效果缺口。
补齐证据后链接测试、固定输入和实际结果并更新状态；不要求每个任务新增条目。

## V-01 提示词约束与视觉多样性

状态：待验证。

- 现有依据：[配图指南](../skills/subaru-slides/references/illustrations.md) 与工程规范采用简短风格提示词；历史单次观察未附可复现输入和生成记录。
- 未知项：约束数量与多样性、内容准确性之间的关系，不能据此推导“约束必然降低质量”。本次不改变现有运行时规则。
- 验证方法：固定 brief、模型版本和其他生成条件，对比不同约束强度并重复生成，盲评多样性、准确性与一致性。
- 边界：[一致性规则](../tools/consistency-rules.json) 仅检测特定文本矛盾，不证明提示词质量，也未全面禁止所有负向约束表达。

## V-06 像素检测的有效性与误报

状态：待验证（检测器已实现，专项回归与性能数据缺失）。

- 现有依据：[检测脚本](../skills/subaru-slides/scripts/detect_pixel_artifacts.py) 与 [QA reference](../skills/subaru-slides/references/qa/pixel-artifacts.md) 定义了三类检测与已知限制。
- 缺口：当前 tests 未覆盖检测器的专项正负样本；历史关于低误报及被删除规则的观察未附可复现实验，不能作为误报率证明。
- 验证方法：建立带人工标注的缺陷图与正常图，逐类验证召回和误报，记录分辨率、阈值、运行时间与跨版面表现。
- 边界：对象遮挡、设计意图和语义仍按生成侧规则与人工检查验收，不扩大自动检测承诺。

## V-07 Brainstorm 行为与对照效果

状态：待验证（包、固定案例与证据检查器已实现；真实配对模型运行尚未完成）。

- 现有依据：[运行入口](../skills/subaru-brainstorm/SKILL.md)、[会话协议](../skills/subaru-brainstorm/references/session.md)、[固定案例与评测](../evals/brainstorm/README.md)。
- 工程覆盖：[单元测试](../tests/test_brainstorm_evals.py) 验证缺记录、缺审阅、伪引用、过期指纹、控制条件差异、分轮缺失等负向条件；synthetic fixture 不作为模型效果证据。
- 未知项：换法的语义差异、延迟判断、冲突分支及跨会话恢复在不同模型中的稳定性；与普通提示词相比是否有帮助。
- 验证方法：同一模型、宿主、参数和基础提示词下，对 cases 目录全部案例两组各运行三次，完整保留 transcript，按 rubric 审阅并记录原文依据；不得选择性保留成功样本。
- 使用观察：2026-10-06 评审的一轮实际咨询中，第三方说法与意愿未知有明确区分，但尚未厘清用户纠结就进入完整建议。仅作单例问题线索，不是配对效果证据；已补充建议与纠结的运行指导及泛化回归案例，优化后的真实行为尚未复测。
- 边界：自评不能称独立验证；审阅记录完整不证明审阅准确，覆盖率通过不代表创造力提升或统计显著优势。当前没有生成器或真实对照证据，不用手写回复填覆盖率。
