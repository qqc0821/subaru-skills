# ADR-003：分别约束安装体积与运行时上下文

状态：已采纳。记录日期：2026-10-06（整理现有设计）。

## 背景

样例资产占用磁盘空间，文本入口与引用链占用模型上下文。二者是不同成本，删除资产不一定减少一次任务的读取量。

## 决策

安装体积继续遵循工程预算；运行时按需读取，并用独立校验器限制声明的必读路径成本。
具体路径、预算与估算公式由 [上下文校验器](../../tools/check_context_budget.py) 维护，本记录不复制数值配置。

## 依据与取舍

相比仅依靠作者自觉，自动预算可以阻止必读文档无意增长。
字符比例估算适合作为回归信号，不等于真实 tokenizer 计数或会话总消耗；声明的路径也不覆盖所有执行分支。
资产保留与否按使用价值判断，不以磁盘字节替代上下文分析。

## 影响

涉及入口的按需标记、风格摘要、参考文档拆分和统一质量门。
安装预算由 [工程规范](../engineering.md) 与 [资产校验](../../tools/check_assets.py) 维护。

## 验证

[Harness 测试](../../tests/test_harness.py) 的 `TestContextBudget` 检查必读路径、最差 preset、超大文件和按需标记；`TestSemanticQualityGuards` 检查损坏标记。
成本复核使用 [context_savings.py](../../tools/context_savings.py) 与校验器的 `--report`；不同时间的测量需注明比较版本与口径，不直接沿用历史百分比。
