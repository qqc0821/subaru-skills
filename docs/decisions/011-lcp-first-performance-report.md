# ADR-011: LCP-first performance report

状态：已采纳

报告默认聚焦导航至 LCP，以 Canvas 展示占用概览与实际任务区间，任务证据保持 HTML 以支持键盘和复制。优先项按当前区间的长任务、占用时长排序；短任务保留在图中，缺少 LCP 时展示完整录制并明确边界。

删除常驻搜索与任务类型切换，以时间选择、任务选择、脚本联动完成排查。超过 50 ms 只作排查信号，不能把执行关联写成 LCP 因果结论。单文件离线交付，无新增依赖。

验证入口：实际采集 HTML 的浏览器交互检查、性能分析器既有单元测试与 make check。图的可读性经实际报告检查，不代表已经验证全部 trace 或设备。
