# ADR-011: LCP-first performance report

状态：已采纳；2026-11-02 经用户认可更新为加载过程与脚本耗时账本。

默认先完整展示导航至 LCP 的加载过程，标记有效的文档首字节和可展开的长任务；缺少 LCP 时展示完整录制，不判断先后。首字节只使用同次 Performance API 快照，不从资源时序反推。

下方以脚本耗时横条呈现所选区间内已去重的关联占用，支持搜索、全部文件展开、任务证据原地展开与完整录制范围切换。未归因工作独立保留。取代旧 Canvas 多轨时间线与常驻侧栏，避免默认局部视窗隐藏加载全貌。用户认可的 A+B 本地原型是视觉依据，通用模板不包含示例站点或固定时长。

超过 50 ms 只作排查信号，执行关联不能写成 LCP 因果结论。单文件离线交付，无新增依赖。

验证入口：实际采集报告与缺失指标 fixture 的浏览器交互检查、分析器单元测试及 make check。视觉认可不代表已验证全部 trace 格式或设备。
