# ADR-010：公开文档与案例证据

状态：已采纳；远端部署与发现效果待验证。

## 背景

首次使用入口缺少实际产物、围绕用户问题的教程与清晰的采用边界。历史本地样稿含较大的资产与宿主路径，不宜直接作为公开安装和效果证明。

## 决策

使用 Python 标准库构建静态文档站，提供对应中英文页面与三个原创案例。版本从 skill 的 `SKILL.md` 派生；运行时规则仍只在那里维护。站点输出留在忽略目录，工作流只上传站点和原创案例，不上传 skill 包或第三方资产。

两份小型原生 PPTX、输入、预览和 receipt 作为明确维护的公开样例；确定性脚本重建人工编写内容，不伪装成模型生成器。Brainstorm 保存单次实际助手产物，不制造用户对话或配对模型证据。

## 取舍与验证

不引入前端依赖、分析服务或动态检索；手动 Pages 部署便于维护者控制上线。小型自有 HTML 模板适合当前内容规模，增长后再评估成熟文档框架。`make check-site` 与负向测试检查本地链接、锚点、元信息、sitemap 和下载 hash；浏览器核对桌面、手机、复制与语言切换。

公开原创案例不补齐 slides 第三方授权；站点存在不证明搜索收录、AI 引用或真实转化。[验证缺口 V-09](../verification-gaps.md#v-09-项目发现与公开文档部署)记录边界，[运营入口](../discovery.md)记录上线与观察方法。
