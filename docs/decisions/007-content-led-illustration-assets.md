# ADR-007：已认可设计基线与内容插图组合

状态：已采纳；视觉效果待用户审阅。

## 背景

FlowDesk v4 改变了相对认可的品牌方向，虽通过结构检查仍被用户否定。
v5 三封面获得整体正向反馈，但没有内页延展证据。配图指南此前要求封面必配图、
只描述情绪及每页整图，与纯排版和原生证据规则冲突。

## 决策与取舍

保留用户认可的设计基线；将逐页视觉计划纳入现有大纲，用用途决定场景、概念、产品或数据表达。
B' 支持局部 cutout、矩形场景和背景；文字、数值、精确关系及产品标签仍原生。
整册风格保持简短，逐页简报允许必要的主体、关系、留白与裁切条件。
先放置代表资产再用参考延展，避免仅凭风格名称批量摆放内容。

详细方法在 skill 的 illustrations、business-design 和 B' 路径维护。
不新增风格登记、强依赖或生成资产入包，不把 FlowDesk 的蓝色玻璃材质变成通用默认。
透明输出需核对实际 alpha，缺能力明确降级。能力探测与宿主实际执行分别记录。

2026-10-06 补充：构建路径与插图来源独立决策，原生与 HTML 路径也主动评估场景资产。
本地 imagegen 目录仅作线索，不能单独触发全 AI 路径；首张正式资产验证宿主调用与输出。
选择已有可用工具，按参考图/编辑/透明能力和代表页效果判断，不维护模型排行榜或新增厂商 SDK。
生成失败后有界修正、采用替代并重排页面，以可完成交付为底线。

## 验证与边界

工程验证使用 make check 和已有相关 eval，不改 baseline 掩盖缺口。
四页 FlowDesk 样稿用于检查封面、问题场景、概念与产品操作的一致性；
生成记录、原生对象检查与逐页渲染留在忽略目录。自评及单次案例不代表独立效果验证，
提示词多样性与跨机字体问题继续记录在 V-01、V-02 和 V-05。
