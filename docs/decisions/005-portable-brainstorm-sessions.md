# ADR-005：对话调度与可携带会话

状态：已采纳；行为改善待验证。

## 背景

仓库新增头脑风暴 skill，需支持换法、分支及续谈；现有 Harness 主要围绕 deck 产物。
宿主对话、文件、搜索能力不同，不能假定数据库、永久记忆或外部 skill 存在。

## 决策

- 由宿主执行阶段切换；阶段与评价约定分开，避免整理时意外解除延迟评价。
- 核心仅依赖对话；用用户可复制的 Markdown 快照续谈，文件能力为可选增强。
- 第一版不增加运行时脚本、第三方依赖或技巧注册表；少量思考动作按需加载。
- 按 skill 声明上下文读取路径，保持 slides 专项预算检查。
- 行为评测采用固定多轮案例与配对运行记录；语义审阅显式区分独立审阅和自评。
- 评测脚本仅核验证据完整性，不把原文引用存在当作审阅准确或创造力提升的证明。

## 取舍与影响

可独立安装、无后台服务，但执行稳定性依赖模型和宿主。
快照可读且可迁移，格式目前由指令维护，未提供确定性合并器或数据库一致性保证。
缺少真实行为记录会导致专用 eval 失败；静态质量门仍独立验证包和工程约束。
重复结果、控制条件及语义判断留存，便于后续复核；未知效果见 [V-07](../verification-gaps.md#v-07-brainstorm-行为与对照效果)。

## 验证入口

`make check`、`make test`、`make eval-brainstorm`。
前两项不替代第三项，测试中的 synthetic 对话只用于验证证据检查器。
