# Lessons Learned

项目级经验沉淀。每次踩坑后追加一条，格式：症状 / 根因 / 修复 / 防回归。
Harness 能自动拦住的，尽量转成对应 check；拦住不了的人工智慧写在这里。

## L-01 【出图】过度约束 prompt 会杀死多样性
- **症状：** 加上颜色比例、构图位置、角色姿势后，10 页只有 1 个雷同角色。
- **根因：** few-shot 与细节约束越细，模型探索空间越小。
- **修复：** base style 只描述情绪与世界观（≤5 行），per-slide 只给内容与感受。
- **防回归：** 文档规则 + H6 eval 看 `font/tone` 多样性（后续可加）。

## L-02 【一致性】反向约束与"描述情绪"原则冲突
- **症状：** 一处要求"始终写 NOT Snoopy"，另两处明确禁止写 NOT。
- **根因：** 不同时期的经验写进了不同文件，没有跨文件一致性检查。
- **修复：** 统一为"不写 NOT 约束"。
- **防回归：** `tools/check_consistency.py` 的矛盾规则。

## L-03 【一致性】分辨率声明必须单一事实源
- **症状：** 同一 skill 内 `1920x1080` 与 `2048x1152` 混用。
- **根因：** 旧模板与新增模板各写各的。
- **修复：** 统一为图像生成 `2048x1152`；HTML 舞台另记 `1920x1080` 并说明换算。
- **防回归：** `single_value` 规则。

## L-04 【一致性】计数多处维护必然漂移
- **症状：** 风格数量出现 18 / 18+5 / 17（样例图）三种说法。
- **根因：** SKILL.md、gallery、样例目录各维护一份计数。
- **修复：** 以 `styles/index.json` 为唯一事实源（P0-5）。
- **防回归：** `check_style_system.py`。

## L-05 【工具】图表部件可能不在 `ppt/charts/`
- **症状：** eval 首次对真实 deck 报 chart_count=0，但文件确实有 3 个原生图表。
- **根因：** 图表实际位于 `ppt/slides/charts/chartN.xml`。
- **修复：** 检测模式改为 `charts?/chart\d+\.xml$`。
- **防回归：** H6 用真实 deck 做回归基准，而不是凭空造 fixture。

## L-06 【Harness】baseline 应"按 check 替换"而非"并集"
- **症状：** 修好一个问题后，它仍留在 baseline 里，永远不会失败。
- **根因：** `--update-baseline` 用并集写入。
- **修复：** 只替换本 check 前缀下的条目，并报告 stale。
- **防回归：** `make check` 输出 stale 提示。

## L-07 【依赖】外部 skill 硬依赖破坏可移植性
- **症状：** Path A 依赖 `$presentations`、配图依赖 `imagegen`，换宿主即失效。
- **根因：** 把"检测到则增强"写成了"必需"。
- **修复：** 能力探测 + 降级（P0-3）。
- **防回归：** `check_consistency.py` 禁止扫描。

## L-08 【仓库】生成物不应入库
- **症状：** `.codex-build/`、`output/`、`.chart-data-*/`、`__pycache__/` 全部未忽略。
- **根因：** 初始仓库没有针对构建/评测产物的 ignore 段。
- **修复：** 补齐 `.gitignore`。
- **防回归：** `check_assets.py` + PR DoD。

## L-09 【转换】复杂 CSS 效果要"快照垫底 + 文字原生"
- **症状：** 渐变/阴影/滤镜在 HTML→PPTX 中整块丢失或导致文字被栅格化。
- **根因：** PowerPoint 无法原生表达这些效果。
- **修复：** 把复杂效果预渲染为底层位图，文字仍以原生文本框绘制在最上层。
- **防回归：** Path C 文档规则 + 交付前逐页目检。

## L-10 【中文】跨机保真需要字体子集或系统回退
- **症状：** 本机正常的 CJK 字体在他人机器上变成方框。
- **根因：** 只声明了字体名，没有嵌入或回退策略。
- **修复：** ① 按实际用字子集嵌入；② 明确系统字体回退栈。
- **防回归：** `references/design/typography-cjk.md` 规则 + 交付前检查（P1）。
