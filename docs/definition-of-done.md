# Definition of Done

本文件把 [开发入口](../AGENTS.md) 的工程底线整理成可勾选清单。
仓库改动交付、PR 提交前检查适用项；方案讨论与只读评审无需执行改动质量门，不适用项说明原因。

## A. 通用（每个改动）
- [ ] `make check` 通过（无新增阻塞项）
- [ ] 变更范围单一，未夹带无关格式化
- [ ] 文档与实现一致（无"文档说 A、实现做 B"）
- [ ] 无 secrets、无 >1MB 二进制、无 `.DS_Store` 与临时产物
- [ ] 路径/重命名已同步修复所有相对链接（`check_links` 通过）
- [ ] 已检查并保留用户已有修改，未覆盖、回退或清理无关工作
- [ ] 跨文件、多阶段或需交接的任务已维护过程三件套；小修改无需三件套，交付说明包含结果
- [ ] 三件套（如有）**未入库**
- [ ] 缺陷修复按风险补充可复现的测试或校验；重要设计取舍更新 [工程决策](decisions/README.md)，常规修复无需新增决策
- [ ] 当前约束在对应规范维护；未验证判断记录证据与 [验证缺口](verification-gaps.md)，未将实现存在当作效果证明
- [ ] 交付说明包含改动、原因、验证与限制；未运行或受阻塞的检查没有被描述为通过

## B. skill 变更
- [ ] `SKILL.md` ≤ 200 行；长文在 `references/`
- [ ] skill 的 `README(.en).md` 只写"是什么 / 怎么用"，未复制 `SKILL.md` 的路径表、能力表或风格计数
- [ ] frontmatter 的 name 与目录名一致；description 写清触发场景
- [ ] `agents/openai.yaml` 字段完整
- [ ] 无外部 skill 硬依赖；能力均有探测与降级路径
- [ ] 风格相关的计数/命名/推荐只引用 `styles/index.json`，不重复维护
- [ ] 新增依赖/资产已在文档说明必要性

## C. 交付质量（deck 产出，P1 起）
- [ ] 会被编辑的文字/表格/图表为原生对象
- [ ] 逐页渲染通过；`validate_pptx` 0 阻塞
- [ ] 无占位符残留；中文无乱码
- [ ] 交付附带 receipt 与 claim_boundary

## D. Harness 变更
- [ ] 脚本或校验器逻辑变更已运行相关测试；影响生成行为或回归覆盖时已运行相应 eval
- [ ] 新增检查有明确 check id 与退出码
- [ ] 有意接受的债务按 [Baseline 机制](harness.md#3-baseline-机制) 记录，未用 baseline 掩盖新增问题
- [ ] 质量门入口一致：`make check` 通过（本地、Agent 与自建 CI 使用同一入口）
