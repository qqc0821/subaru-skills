# subaru-brainstorm

帮助你换角度想问题、展开不同路线，并在暂停后接着讨论的头脑风暴 skill。

[English](README.en.md)

安装后交给宿主 Agent，例如：

> 用 $subaru-brainstorm 探索这个产品还能有什么用途，给我 50 个想法，先别评价。

也可以从模糊需求开始：

> 用 $subaru-brainstorm 想想怎样让团队讨论更容易接续。先给几个不同入口。

讨论中直接说“沿第三条继续”“合并这两个”“这些太相似，换个思路”或“现在整理成方案”。
它会保留你引用过的方向，让你的点子继续发展。

暂停时说“给我一份续谈摘要”，下次把摘要贴进对话并要求继续；宿主支持文件时也可要求保存。
跨会话接续依赖你提供摘要或文件，不保证宿主永久记忆。

基础能力只需要对话。搜索、文件保存、分支图和其他产物取决于宿主工具是否可用；
没有文件工具时仍可获得可复制摘要。生成的想法和情境需要实际验证。
