# Writing Quality (中文)

生成前自检，避免"AI 味"。这是负例库，不是绝对规则，但默认应当避免。

## 五类坏文案
1. **生硬/翻译腔**：把英文直译。如"进行一个优化" → "优化"。
2. **浮夸/空泛**："赋能""抓手""闭环""颠覆""重塑""生态位""护城河""多维度立体化"。
3. **含糊**："一定程度上""某种意义上""相关""各种"——能删就删。
4. **冗余**："进行了讨论" → "讨论了"；"能够" → "能"。
5. **不合逻辑**：因果/主次关系错误。

## 七类 AI-isms
1. 标点：滥用破折号、分号、"•"、竖线、箭头。
2. "不是 X，而是 Y" / "与其 X，不如 Y" 的排比套路。
3. 被动句堆砌。
4. 祈使句标题（"让我们……""开始之前……"）。
5. slogan 式句式。
6. 三段式堆砌（"X、Y 和 Z"反复出现）。
7. 不必要的连字符复合词。

## 标题
- 只用标题就能读出整个故事（像书的目录）。
- setup/overview/definition 页用简洁名词短语；finding 页用断言句。
- 短标题不加句号；不要为了"金句"制造悬念或张力。
- 避免"从 X 到 Y""关于……的两个问题"等泛化框架。

## 自检清单
- [ ] 删掉所有能删的形容词与套话。
- [ ] 每个标题都是可验证的陈述或清晰的名词短语。
- [ ] 没有"不是 X 而是 Y"式排比。
- [ ] 数据/引用有来源（slide 或备注）。
