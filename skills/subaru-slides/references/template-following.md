# Template / Brand Following

Use when the user provides an existing deck or brand system to follow.

## Four steps
1. **Decide the purpose** - edit / match design / take inspiration / content only.
   A deck used only as a content source does **not** mean copying its design.
2. **Recon before editing** - render the source pages; inspect slide size, layouts, title/body positions,
   fonts, colors, logo, image crops, footers. Use the actual reference; do not rely on memory or assume 16:9.
3. **Reuse structure, edit in place** - work on a copy; duplicate/fill placeholders; preserve
   size/master/layout/theme/fonts/spacing/image styles/repeated elements; prefer editing a single slide
   over the shared master; fit new content into the existing layout instead of covering it; delete unused
   placeholders but keep required template elements; never add slides when the count is fixed; PDF/image
   references must be rebuilt as editable objects.
4. **Verify side by side** - compare every slide that uses a changed master/layout against the source.
   A successful import or render does **not** prove the template was preserved.

## Hard rules
- **Template slots != source items**: if a template group has 4 members and you have 3, delete the 4th
  group's image **and** its text boxes - do not leave empties.
- **Do not mask**: never cover inherited content with a large opaque shape; edit it instead.
- **Prefer slide-level edits over master/layout edits.**
- **Record which slides changed.**
- Do not claim fidelity without a side-by-side comparison; a coverage ratio is not proof of a visual match.
