# 温暖漫画风的应用参考

仅在选定 `../styles/warm-comic-strip.md` 后需要场景示例时读取。
调色板与 Base Style Prompt 只在该 preset 维护；资产制作和提示词条件见 `illustrations.md`。

## 场景选择

用简洁角色与日常行动表达主题：例如桌前协作、观察星空或分享发现。
保留轻松、温暖的情绪；角色动作应与本页内容有关，不只充当装饰。
风格参考不意味着必须出现特定角色，用户有明确角色要求时按其要求处理。

## 局部资产简报示例

```text
用途：培训页的局部场景插图，解释两人核对同一项工作。
视觉语言：[warm-comic-strip 的 Base Style Prompt]。
主体与行动：两位简洁漫画人物在桌前共同查看记录，姿态自然。
装配条件：横向矩形场景，主体完整；图片无文字，标题和标签原生叠加。
```

将资产放入实际页面，检查动作是否清楚、线条是否一致、文字是否易读。
封面与内容页可共享角色和色彩，但按页面用途改变场景；不要把一次生成结果
当作提示词效果或视觉多样性的普遍证据。
