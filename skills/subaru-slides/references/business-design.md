# 商业演示的参考研究与设计落实

适用于商业研究、产品推广、管理层汇报，或用户反馈“随意、模板感强、缺少高级感”。
入口规则见 `../SKILL.md`；此处提供执行方法，不另设审批步骤。

## 1. 先判断目的与观看方式

- 研究报告用证据支持判断；产品推广用产品价值、使用情境和行动建立说服。两者不能共用一套审美预设。
- 设计重做先保留用户相对认可的颜色、字体或构图，定位失败项再改；研究新参考不等于授权整体换风格。
- 现场演讲：一句主要信息、一份主要证据；细节进备注或附录。
- 屏幕阅读报告：可增加解释、方法和并列图表，但仍须有明确阅读顺序。
- 不把知名机构的密集报告直接缩放成销售演示。品牌知名度不是设计质量证明。

## 2. 从真实内容页建立参考

从 `business-references.md` 选与当前任务相近的 2–3 份，或使用用户提供的参考。
研究稿观察证据组织；推广稿优先寻找同类产品发布或品牌演示。研究报告封面可借构图，但不能证明其内容版式适合销售。
每份至少看封面、一张证据页和一种不同构图；网站首页、模板缩略图不算内容页参考。
用户要求研究更多样本时按要求完成，不将每次制作固定成十份研究。

写下来源、版本、PDF 物理页码、实际查看范围和以下四项：

| 观察 | 转成当前项目的决定 |
|---|---|
| 最大的视觉区域是什么，读者先看哪里 | 每页的主要证据及面积分配 |
| 标题、解释、标签、注释如何区分 | 固定字号角色、字重和文字色 |
| 哪些边界对齐，哪些间距反复出现 | 统一左右边距、基线和内容起点 |
| 颜色如何指向重点，版式如何变化 | 强调色语义及整册页面节奏 |

只借鉴设计方法；不用参考报告的客户、数字、品牌或图像填充当前内容。
无法查看原页时标记“仅检索到”，不写成已完成视觉审阅；离线时可使用本地参考。

## 3. 写一份简短设计契约

重做先记录已认可的基线：颜色、字体关系、构图、图片材质与用户反馈；说明本轮要解决的问题。
将基线作为比较依据，不因研究新参考擅自替换。认可封面不等于认可整册，内页仍需样稿验证。

选择一套连贯的视觉方向，不能把不同参考的颜色、字重、布局机械拼接。
在构建前固定以下项目，并给出对应参考页；不要只写“商务蓝、简洁、高级”。

- **文字**：已验证的中文字体与真实字重、foundation profile、标题/正文/标签/注释角色。
- **网格**：页边距、页眉页脚位置、主内容区；标题两行时的下移规则。
- **颜色**：底色、正文、次要文字、一个主要强调色；风险/状态色有独立语义。
- **证据**：图表、原生表格、可编辑流程、产品界面或原始图片，说明它支持什么。
- **节奏**：封面、结论+证据、比较、产品演示、决策页各自的构图职责。

字体搭配与样张方法见 `typography-cjk.md`；不要让封面的字号和字重支配所有内容页。

## 4. 页面组织

**封面**：品牌、题目和必要说明构成一个文字组。视觉资产应与题目有关；
其色彩或构图语言需要能延续到内容页。大面积抽象图不是内容页质量的替代品。
也可以用纯排版封面，不为“每页有图”添加无意义装饰。

**结论+证据**：有证据时才使用结论标题。为图表保留主视觉位置，
直接标注关键数据和单位，辅助信息退到次层。别把证据挤成标题下的小附件。

**比较/流程**：比较维度决定列，顺序或因果决定连接；平行关系不用箭头。
优先对齐与间距，不默认给每个要点套等宽卡片；等权信息才等面积。

**产品页**：界面用于解释一个具体任务，选择相关局部放大，而非缩小整个产品。
界面内只放真实或明确标为示意的 UI 信息；演示解说放在界面外。
不因缩小字体营造“真实密度”；标签下限仍按 foundation，必要时减少界面字段。

**数据页**：有可比尺度才并排对比。实测、估计与预测明确区分；
颜色、面积和坐标轴不能夸大差异。截图中的图表不可冒充原生编辑对象。

## 5. 关键页验收

用户否定整体审美时，先用同文案制作少量完整方向，展示参考与样稿的对应关系；不能只给色板或字号表。
方向未定时不扩展全稿，不把未获认可的审美偏好写成通用默认值。
方向明确后构建封面、最密的内容页、最重要的证据/产品页；至少做一次渲染审阅。
按已有合作模式处理反馈，不额外创造批准流程。具体改动后再扩展同类页面。

| 审阅问题 | 失败时怎么改 |
|---|---|
| 缩到约 25% 时，能否分辨主要信息与次要信息 | 缩短标题、压低辅助元素权重，放大证据 |
| 全尺寸时中文是否拥挤、发虚、机械加粗或断句别扭 | 换真实字重、调文本框宽度和行距；不盲目放大 |
| 留白是否把相关内容组织在一起 | 按内容组调整间距，别将空白平均铺满 |
| 连看三页是否只有同一种顶部大标题+三卡片 | 根据比较、证据、过程等真实关系重新组织 |
| 每个强调都有清楚理由吗 | 删除无关色块、装饰线、英文标签和重复小标题 |
| 参考的优点是否落到了具体对象 | 写下“参考页 → 本页决定”，不能只改颜色 |

自动结构检查只能发现部分缺陷。未溢出、已对齐、字体存在，不等于设计已经达到预期。
