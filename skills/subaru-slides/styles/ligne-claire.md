# 清线漫画 (Ligne Claire Comics)

**一句话：** 均匀线条 + 平涂色块 = 零视觉噪音，信息清晰度最高。

## Base Style Prompt

```
VISUAL REFERENCE: Hergé Tintin — maximum information clarity through visual restraint.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: cream background, uniform black outlines, flat saturated fills, no gradients.
Panel-based sequential reading; each panel advances one idea.
```

## 版式组件
- cover
- 2-4 panel sequence
- diagram panel
- caption box

## 注意事项
- 不要用渐变或阴影
- 情感张力较弱，适合信息型内容
