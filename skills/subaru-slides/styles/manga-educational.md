# 学習漫画 (Manga Educational)

**一句话：** 角色带着读者学习，用反应与戏剧性强化重点。

## Base Style Prompt

```
VISUAL REFERENCE: Japanese educational manga (学習漫画) — a character GUIDES you through the concept with reactions.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: bright warm palette, white background, screen-tone gray for explanation areas.
Dynamic panels and reaction faces (surprise, eureka) drive the teaching.
```

## 版式组件
- cover
- 3-5 panel explainer
- reaction close-up
- summary panel

## 注意事项
- 面板不要过多
- 对话泡是信息容器，不要把正文塞满画面
