# 苏联构成主义 (Soviet Constructivism)

**一句话：** 力量感与几何精确性，辨识度极高。

## Base Style Prompt

```
VISUAL REFERENCE: 1920s Rodchenko propaganda poster — power through geometry.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: revolutionary red, black, cream — three colors only, NO gradients.
Diagonal wedge from bottom-left to top-right; geometry grows small to large; text rotated.
```

## 版式组件
- cover
- diagonal manifesto
- step crescendo
- closing call

## 注意事项
- 严格三色，不要加第四色
- 不要水平线
