# xkcd白板手绘 (Whiteboard Sketch)

**一句话：** 极简幽默，复杂概念秒懂。

## Base Style Prompt

```
VISUAL REFERENCE: xkcd What If? meets a professor whiteboard after an exciting lecture.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: pure white background, black ink, ONE accent color for the key insight.
Stick figures, wobbly charts, annotation arrows, hand-written feel.
```

## 版式组件
- cover
- freeform diagram
- before/after doodle
- key number

## 注意事项
- 只有一个强调色
- 不要追求精致，潦草反而真实
