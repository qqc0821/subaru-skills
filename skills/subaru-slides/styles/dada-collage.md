# 达达拼贴 (Dada Collage)

**一句话：** 反规则，最另类。

## Base Style Prompt

```
VISUAL REFERENCE: Dada cut-paper collage — organized chaos.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: no fixed palette; paper white, ink black, brand red, tape yellow, random color.
Torn paper, mixed typefaces, tape and pins, rubber-stamp data.
```

## 版式组件
- cover
- torn-paper panel
- stamp data
- closing

## 注意事项
- 混乱要有秩序感
- 不要过度整洁
