## Base Style Prompt

```
VISUAL REFERENCE: Monument Valley isometric illustration.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: light gray-blue ground, one pastel color per platform.
2.5D view, ascending platforms, small figures climbing the steps.
```
