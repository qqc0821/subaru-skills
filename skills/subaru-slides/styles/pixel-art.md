# 像素画RPG (Pixel Art RPG)

**一句话：** RPG 任务隐喻，gamification 首选。

## Base Style Prompt

```
VISUAL REFERENCE: 16-bit RPG world map.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: 16-bit palette — sky blue, grass green, UI navy, gold.
Pixel characters in zones, quest progress bar, dialogue box.
```

## 版式组件
- cover
- world map
- quest progression
- dialogue box

- 不要抗锯齿
