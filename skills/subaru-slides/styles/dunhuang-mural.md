# 敦煌壁画 (Dunhuang Mural)

**一句话：** 东方美学，庄重诗意。

## Base Style Prompt

```
VISUAL REFERENCE: Dunhuang cave murals — scroll narrative, mineral pigments.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: ochre ground, mineral azurite/cinnabar/malachite/gold; matte, not digital-bright.
Apsaras ribbons carry the eye from left to right; clouds and lotus motifs.
```

## 版式组件
- cover
- scroll narrative
- four-stage journey
- closing mural

## 注意事项
- 不要用佛教人物形象，用飞天意象即可
- 避免数码高饱和
