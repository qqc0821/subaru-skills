# 孔版印刷 (Risograph)

**一句话：** 双色叠印独特美学。

## Base Style Prompt

```
VISUAL REFERENCE: Risograph two-color print.
CANVAS: 16:9, 2048x1152, high quality.
COLOR SYSTEM: paper cream, fluorescent pink + blue, overprint purple; halftone dots; 2-3px misregistration.
Rough paper texture, limited two inks.
```

## 版式组件
- cover
- two-ink poster
- overprint chart
- closing

## 注意事项
- 严格双色叠印
- 不要数码渐层
